# 横スクロールアクションのギミック追加ガイド

## 1. エンティティに画像（トゲなど）を設定する方法
現在のプログラムは、**「LDtk上で設定されたエンティティの画像」を自動的にゲーム内に反映**する仕組みになっています。
トゲ（Spike）やその他のギミックに画像をつけるには、以下の手順をLDtk上で行うだけで完了します！

1. LDtkエディタの右側パネルで、対象のエンティティ（例: `Spike`）の設定画面を開く
2. **Editor visual** の項目を `Tile` に変更する
3. すぐ下に表示されるタイルセットの画像から、トゲとして使いたい画像を選択する
4. セーブしてブラウザを更新すると、プログラム側が自動的にその画像を読み取り、ゲーム画面に表示します！
※ ただし `DeathZone` や `Magma` のように「見えない判定として使う設定」になっているものは画像が非表示になります。

## 2. 横スクロールで追加できるギミックのアイデアと実装方法

### ① 流れる床（ベルトコンベア）
- **LDtk設定**: `Conveyor` エンティティを作成し、カスタムフィールド `speed` (Float) を追加。画像をタイルのコンベアにする。
- **実装方法**: `main.ts` で `conveyor` グループを作り、プレイヤーとの衝突判定 (`collider`) 時に、プレイヤーのX座標や速度を `speed` 分だけ強制的に動かします。

### ② 一定時間で消える床（ちくわブロック）
- **LDtk設定**: `CrumbleBlock` エンティティを作成し、カスタムフィールド `delay` (Float, 落下までの秒数) を追加。
- **実装方法**: プレイヤーが上に乗った瞬間（衝突判定の `touching.up`）にタイマーを起動し、指定時間後にブロックの物理判定をオフにして画像を半透明化/非表示にします。数秒後に復活させるタイマーも組み込みます。

### ③ 落ちてくるトゲ
- **LDtk設定**: `FallingSpike` エンティティを作成。
- **実装方法**: トゲの下方向に透明な「検知ゾーン」を持たせ、そこにプレイヤーが入ったらトゲの重力をオン（`body.allowGravity = true`）にして落下させます。

### ④ 傾く床・坂道（スロープ）について
- **重要**: 現在使用している物理演算エンジン（Phaser 3 の Arcade Physics）は、「四角形」と「円」の当たり判定に特化しており、**斜めの坂道判定が苦手**です。
- もし坂道を本格的に導入したい場合は、階段状にタイルを並べるか、カスタムコードで「坂道の上を歩く時はプレイヤーのY座標を滑らかに上げる」補正処理を書く必要があります。

## 3. 全体ワークフロー：新しいギミックを追加する手順

新しいギミックを思いついたら、以下の **4ステップ** で追加していきます。

### Step 1: LDtkでエンティティを定義する
- **エンティティ作成**: 名前、サイズ、色を決める
- **見た目**: Editor visual を Tile にして画像を割り当てる
- **パラメータ**: ギミック固有の数値（スピード、体力回復量、イベント名など）を Custom Fields で定義する

### Step 2: プログラム（`main.ts`）でパースする
`main.ts` の `// エンティティからギミックを生成` と書かれているループ（for文）の中に、新しい `if` を追加します。
```typescript
} else if (e.identifier === '新ギミックの名前') {
    const speed = e.fields?.speed ?? 100; // フィールドの読み取り
    // グループに追加したり、専用クラスを生成する
}
```

### Step 3: 専用クラスの作成（複雑な場合）
動く床(`MovingPlatform.ts`)や会話NPC(`NPC.ts`)のように、毎フレーム独自の動きをするものは専用のクラスを作ります。ただの静的なブロックであれば、`main.ts` の中で `group.create()` するだけで十分です。

### Step 4: プレイヤーとの当たり判定を登録する
`main.ts` の下の方で、プレイヤーとの衝突(`collider`)や重なり(`overlap`)を設定し、触れた時の効果を書きます。
```typescript
this.physics.add.collider(this.player, 新ギミックのグループ, (player, gimmick) => {
    // 触れた時の処理（ダメージ、ワープ、床を消す など）
});
```

この流れを繰り返すことで、いくらでも新しいギミックを拡張していくことができます！次に作ってみたいギミックがあれば、専用クラスの土台を作成しますのでお知らせください。
