# ゲームシステム：White Monolith

## 基本システム
- **2Dサイドビュー・探索アクション**
- **記憶継承ループシステム**: 1周目クリア後のフラグ管理により、テキスト表示を「文字化け」から「正常」へ切り替える。
- **カメラシステム**: プレイヤーの動きを滑らかに追いかける「Smooth Follow」（実装検討中）。

## 対話・テキストシステム
- **NPCとの会話開始**:
  - NPCに一定距離（触れるか触れないかの距離）まで近づくと、自動でNPCの頭上に小さな `...` の吹き出しが表示される。
  - その状態で**左クリック**をすることで会話（ダイアログ）を開始する。
- **ダイアログ表示**:
  - 外枠・文字：白ピクセル / 背景：黒
  - 1周目：文字化け
  - 2周目：デコードされた正常な文章
- **主人公のテキスト**:
  - **心の声**: 丸括弧 `()` で囲んで表示（例：`(どう考えても異様な状況だ……)`）。これは実際に声に出しているわけではない描写。
  - **通常のセリフ**: 括弧なしで表示。

## 移動・アクション
- **基本移動**: **Aキー（左）** / **Dキー（右）**
- **浮遊ジャンプ**: **Wキー**（幽霊らしい、ふわっとした低重力感のある上昇）
- **インタラクト**: 色のついたオブジェクト（重要アイテム）への接触。重要アイテムでも色がついていないものも存在する。
- **ギミック**: 複数の機能を持った塔の内部構造を利用した仕掛けの解決。
- **浮遊システム**: 
  - 主人公は常に地面から一定の高さ（ホバリング高度）を維持する。
  - 入力システムにはUnityの **Input System Package** を使用する。

## 演出
- **URP 2D Bloom**: 黒背景の中で、クリスタルの青や重要オブジェクトの色が鮮やかに発光する。
- **ホワイトアウト**: 1周目終了時の画面遷移。
